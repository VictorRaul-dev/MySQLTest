Guía de práctica y compatibilidad

Importación: todas las hojas no vacías de Excel; CSV con campos entrecomillados. Las columnas numéricas de Excel se reconocen como INTEGER/REAL; CSV conserva texto (incluidos ceros iniciales). Usa CAST(columna AS REAL) para cálculos sobre CSV. Las celdas vacías son NULL; las fechas de Excel se guardan como texto ISO. Las fórmulas requieren un resultado guardado por Excel.

Equivalencias: TOP n / TOP (n) en SELECT simple; dbo.Tabla; ISNULL; GETDATE() (hora local del navegador); LEN (ignora espacios finales); cadenas N'texto'; VARCHAR/NVARCHAR(n) como TEXT.

Práctica disponible: SELECT, WHERE, JOIN, GROUP BY, HAVING, ORDER BY, CASE, CTE, INSERT, UPDATE, DELETE, CREATE TABLE y DROP TABLE, dentro de las capacidades de SQLite.

No es SQL Server real: tipos, división entera, fechas, ordenación y comparación pueden diferir. No incluye procedimientos, variables @, tablas #temporales, IDENTITY, DATEADD, DATEDIFF, MERGE, APPLY, TOP PERCENT/WITH TIES, SELECT INTO ni control manual de transacciones. Se rechazan las formas conocidas no compatibles; otras sintaxis pueden producir errores de SQLite.

Recuperación: cada ejecución o importación se aplica completa o se revierte si falla. Deshacer recupera el estado anterior a la última operación. Guarda un punto de restauración antes de experimentar. Detener cancela la tarea en curso y recupera la última base completada. El límite automático es de 30 segundos.

Exportación: descarga las filas visibles como CSV. Los valores que pueden interpretarse como fórmulas de Excel se protegen con un apóstrofo.
